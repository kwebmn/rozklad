# Rozklad — Android-приложение расписания УКД

Дата: 2026-10-15
Репозиторий: https://github.com/kwebmn/rozklad

## Цель

Удобный просмотр расписания с сайта «ПС-Розклад» Університету Короля Данила
(`http://195.162.83.28/cgi-bin/timetable.cgi?n=700`). На сайте неудобная форма,
группа не запоминается. Приложение запоминает выбор: открыл — сразу видишь пары.

**Критерии успеха**
- После первой настройки расписание на сегодня видно за одно открытие приложения, без ввода.
- Расписание доступно без интернета (последние загруженные данные).
- Пользователь узнаёт об изменениях в расписании и о ближайшей паре через уведомления и виджет.
- Новая версия ставится из приложения, без ручного поиска APK.

**Распространение:** APK собирает GitHub Actions, выкладывается в GitHub Releases. Google Play вне рамок.
Интерфейс на украинском.

## Источник данных (исследовано)

Сайт: ПС-Розклад v5.2, кодировка **windows-1251**, только HTTP.

| Назначение | Запрос |
|---|---|
| Автокомплит групп | `GET timetable.cgi?n=701&lev=142&faculty=<id>&course=<n>&query=<cp1251-urlencoded>` → JSON `{"query":..,"suggestions":[..]}` |
| Автокомплит преподавателей | `GET timetable.cgi?n=701&lev=141&faculty=<id>&query=<cp1251>` → тот же формат |
| Расписание по имени | `POST timetable.cgi?n=700`, form: `faculty=0&teacher=<cp1251>&course=0&group=<cp1251>&sdate=dd.mm.yyyy&edate=dd.mm.yyyy&n=700` |
| Расписание по ID | `GET timetable.cgi?n=700&group=<id>&sdate=..&edate=..` (для преподавателя — `teacher=<id>`, проверено: `teacher=66`) |

Факультеты (`faculty`): 0 — все, 1001 Факультет суспільних і прикладних наук, 1002 Фаховий коледж,
1004 Факультет медицини (1003 — «.», скрывать). Курс: 0–6.

Ответ расписания — HTML. В заголовке `<h4>` постоянная ссылка с ID
(`href="./timetable.cgi?n=700&group=-607&..."`). Дни: `<h4>DD.MM.YYYY <small>День</small></h4>`, за ним таблица;
строка `<tr><td>N</td><td>HH:MM<br>HH:MM</td><td class="rozklad-cell-text">…</td></tr>`.
Ячейка содержит (возможно несколько занятий):
`span.p_name` (предмет), `span.p_type_name` (Л/Пр/…), `span.gr2_name` (поток, опционально),
`span.t_name` (преподаватель), `span.room_name` (аудитория). Пустая ячейка — нет пары.
Возможен класс `.remote_work` (дистанционно) — сохранять как флаг.

## Стек

Kotlin, Jetpack Compose (Material 3, тёмная тема, dynamic color), Room, DataStore, OkHttp, Jsoup,
kotlinx.serialization, WorkManager, Glance (виджет), AlarmManager. Один модуль `app`.
minSdk 26, targetSdk/compileSdk — последний стабильный. Без DI-фреймворка (ручной `AppContainer`).

## Архитектура

```
data/remote   ScheduleApi     — HTTP, cp1251 кодирование запросов/декодирование ответов
              ScheduleParser  — HTML → ParsedSchedule(siteId, lessons)
              SuggestParser   — JSON автокомплита → List<String>
              UpdateApi       — GitHub Releases API
data/local    Room: LessonEntity, SubscriptionEntity; DataStore: настройки
data/         ScheduleRepository — подписки, загрузка периода, запись в кэш, diff
              UpdateRepository   — проверка/скачивание обновления
domain/       Subscription, Lesson, LessonChange; чистая логика (diff, выбор дня, версия)
ui/           экраны Compose + ViewModel
widget/       Glance-виджет (читает только Room)
work/         SyncWorker, ReminderScheduler, ReminderReceiver, BootReceiver
```

**Модели**
- `Subscription(id, type: GROUP|TEACHER, name, siteId, isPrimary)`
- `Lesson(subscriptionId, date, pairNo, start, end, subject, kind, teacher, room, stream?, remote)`;
  ключ — (subscriptionId, date, pairNo, индекс занятия в ячейке).

**Принципы**
- Room — единственный источник правды для UI, виджета и напоминаний. Сеть пишет только в Room.
- При добавлении подписки: POST по имени → извлечь ID из постоянной ссылки → сохранить. Далее GET по ID.
  Если ID не найден — fallback на POST по имени.
- `network_security_config`: cleartext разрешён только для `195.162.83.28`.

## Экраны

1. **Додати розклад** — переключатель Група/Викладач, фильтры факультет/курс (опционально),
   поле с автокомплитом (от 2 символов для групп, 3 для преподавателей, debounce). Выбор → подписка
   (первая становится основной) → главный экран.
2. **Главный** — в шапке выбор подписки (▾), обновить, настройки. Полоса дней недели, свайп между
   неделями. Список пар дня: номер, время, предмет, тип, преподаватель (сокращённо), аудитория, поток;
   «вікно» для пустых пар между занятиями; подсветка текущей пары. Открывается на сегодня, если пары
   сегодня закончились — на ближайший следующий день с парами. Pull-to-refresh. Плашка
   «Оновлено …» / «Офлайн, дані від …». Тап по паре — нижний лист с деталями.
   Пустой день — «Пар немає».
3. **Налаштування** — подписки (удалить, сделать основной, добавить), напоминания (вкл, за 5/10/15/30 мин,
   по умолчанию 10), уведомления об изменениях (вкл), тема (системная/светлая/тёмная),
   «Перевірити оновлення», версия.
4. **Виджет** (4×2, resizable) — основная подписка: день, текущая/следующая пара выделена, остальные пары
   дня (время, предмет, аудитория); после последней пары — пары следующего учебного дня. Тап → приложение.

## Синхронизация

- Окно: с понедельника текущей недели на 2 недели вперёд, по каждой подписке, один запрос на диапазон.
  Ручное листание за пределы окна грузит неделю по запросу.
- `SyncWorker`: периодически раз в 4 ч, constraint — сеть. Шаги: загрузить → распарсить →
  diff с Room (только даты ≥ сегодня) → заменить данные периода → обновить виджет → перепланировать напоминания.
- Если diff по **основной** подписке непустой и уведомления об изменениях включены — уведомление
  «Розклад змінився» с перечнем изменений (до 5 строк + «ще N»). Первая загрузка подписки уведомлений не даёт.
- Напоминания: `AlarmManager.setExactAndAllowWhileIdle` на пары ближайших 24 ч основной подписки;
  без разрешения точных будильников — `setAndAllowWhileIdle`. Перепланирование после синхронизации,
  изменения настроек и `BOOT_COMPLETED`. Текст: «Через 10 хв: Prompt-інжиніринг (Пр), ауд. 330/5к».
- Android 13+: запрос `POST_NOTIFICATIONS` при первом включении уведомлений.

## Обновление через GitHub

- `GET https://api.github.com/repos/kwebmn/rozklad/releases/latest`; сравнить `tag_name` (`vX.Y.Z`)
  с `BuildConfig.VERSION_NAME` семантически.
- Автопроверка при запуске приложения не чаще раза в сутки; ручная — кнопкой в настройках.
- Есть новее → диалог: версия + `body` релиза → «Оновити» / «Пізніше».
- Скачивание asset `*.apk` через `DownloadManager` в app-specific external dir, затем установка через
  `FileProvider` + `ACTION_VIEW` (`application/vnd.android.package-archive`). Разрешение
  `REQUEST_INSTALL_PACKAGES`; если «невідомі джерела» не разрешены — отправить в системные настройки.
- Ошибки сети при проверке — молча (автопроверка) или тост (ручная).

## Ошибки

- Нет сети / сайт недоступен / таймаут (15 с): показываем кэш, плашка «Офлайн», worker — retry с backoff.
- Страница без ожидаемой разметки (нет заголовка «Розклад групи/викладача») → `ParseException`,
  кэш **не трогаем**, сообщение «Не вдалося розібрати відповідь сайту».
- Ответ с заголовком, но без дней — валидно пустой период.

## Тестирование

- Unit: `ScheduleParser` на фикстурах HTML (группа, преподаватель, пустой период, несколько занятий
  в ячейке, поток, remote_work, мусорная страница), `SuggestParser`, cp1251-кодирование,
  diff, выбор стартового дня, сравнение версий, вычисление ближайших напоминаний.
- ViewModel — unit-тесты с фейковым репозиторием.
- Инструментальных тестов в CI нет.

## CI/CD (GitHub Actions)

- `ci.yml` (push, PR): JDK 17, `./gradlew testDebugUnitTest assembleDebug`, debug APK — artifact.
- `release.yml` (тег `v*`): `versionName` из тега, `versionCode = major*10000 + minor*100 + patch`;
  подписанный release APK (`rozklad-vX.Y.Z.apk`) прикладывается к GitHub Release, тело — из
  сообщения тега / автогенерации.
- Подпись: secrets `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
  Один keystore на все релизы (иначе обновление поверх невозможно).
- Локально Android SDK нет; проверка сборки — через Actions.
